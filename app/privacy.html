개인정보처리방침 (Privacy Policy)

시행일: 2026년 11월 8일 · 대상: 콘텐츠 공장 (Content Factory)

1. 누가 쓰나요

이 앱은 운영자 본인만 사용하는 개인용 도구입니다. 다른 사람의 계정에 연결하거나 다른 사람의 정보를 모으지 않습니다.

2. 어떤 정보에 접근하나요

  • YouTube: 운영자 본인 채널에 영상을 올리고 예약 공개를 설정하며, 본인 채널의 영상 목록과 조회수 같은 통계를 읽습니다.
  • Google Drive: 이 앱이 직접 만든 폴더와 파일만 만들고 옮깁니다 (drive.file 범위). 드라이브의 다른 파일은 볼 수 없습니다.

3. 어떻게 보관하나요

로그인 승인 정보(토큰)는 운영자의 컴퓨터와 개인 서버에만 저장하며, 운영자 외에는 접근할 수 없습니다.

4. 공유하나요

Google 사용자 데이터를 판매하거나 제3자에게 공유하지 않으며, 광고에 사용하지 않습니다. 이 앱의 Google API 데이터 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

5. 삭제

운영자는 언제든지 Google 계정 권한 페이지에서 이 앱의 접근을 해제할 수 있으며, 저장된 토큰은 그때 삭제합니다.

English summary

Content Factory is a private tool used only by its owner. It accesses only the owner's own YouTube channels (upload, scheduling, channel statistics) and only the Google Drive files it creates itself. Tokens are stored only on the owner's own devices. Google user data is never sold, shared with third parties, or used for advertising, and its use complies with the Google API Services User Data Policy, including the Limited Use requirements.
